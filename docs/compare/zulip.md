There's no migration here. Zulip is a different chat with its own way of organizing conversations, and SlackVault has no import from it. SlackVault is for a team that's staying in Slack.

## Where to start

If that's you: [Slack app setup](/guides/slack-app-setup), then [Firebase setup](/guides/firebase-setup), then the [browser extension](/guides/browser-extension). The first sync is covered in [Syncing & your archive](/guides/syncing-and-archive).
